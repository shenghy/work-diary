# 极简工作日记 · 微信小程序版

基于 **uni-app（Vue 3 + Vite）** 开发的微信小程序，复用现有 FastAPI 后端
（`https://work.jspang.com`），与桌面版 / Android 版数据互通（LWW 云端同步）。

## 目录结构

```
work_diary_miniprogram/
├── src/                      # uni-app 源码
│   ├── pages/
│   │   ├── login/            # 登录 / 注册 / 找回密码（邮箱+验证码）
│   │   ├── tasks/            # 主页面：顶部 5 标签（计划中/执行中/已完成/全部/备忘）
│   │   │                     #   任务视图 + 备忘视图（与桌面端一致）
│   │   ├── task-edit/        # 新建 / 编辑任务（多行标题 + 子任务自动转义）
│   │   ├── memo-edit/        # 备忘编辑
│   │   └── mine/             # 个人中心（账号/退出）
│   ├── components/
│   │   └── task-card.vue     # 任务卡片（色条边框/进度条/勾选子任务/操作按钮）
│   ├── utils/
│   │   ├── api.js            # 请求封装（Bearer token、401 跳登录）
│   │   ├── auth.js           # 登录态管理
│   │   ├── sync.js           # 云端同步（/sync 全量 LWW 合并）
│   │   ├── drag-sort.js      # 长按拖拽排序纯逻辑（可单测）
│   │   ├── subtask.js        # 子任务解析（移植桌面端 subtask_parser.dart）
│   │   ├── storage.js        # 本地缓存（离线可用）
│   │   └── util.js           # 时间格式化 / 文案 / 配色
│   ├── App.vue / main.js / pages.json / manifest.json
├── dist/build/mp-weixin/     # 正式构建产物（发布用）
├── dist/dev/mp-weixin/       # 开发模式产物（watch 热更新，工具导入此目录）
└── package.json
```

## 本地运行

```bash
npm install
npm run dev:mp-weixin     # 开发模式（watch 热更新，导入 dist/dev/mp-weixin）
npm run build:mp-weixin   # 构建正式包（导入 dist/build/mp-weixin）
```

### 开发热更新流程（推荐）

1. 运行 `npm run dev:mp-weixin`（终端保持运行，监听 `src/` 变化自动增量编译）
2. 微信开发者工具 → 导入项目 → 目录选择 **`dist\dev\mp-weixin`**
3. 详情 → 本地设置 → 勾选「文件保存后自动重新编译」（热重载）
4. 改代码 → 保存 → 自动重编译 → 工具自动刷新，**无需清缓存**
5. 发布前：停掉 dev 进程 → 跑 `npm run build:mp-weixin` 生成正式包

微信开发者工具导入步骤（build 模式）：
1. 打开微信开发者工具 → 导入项目
2. 目录选择 `dist\build\mp-weixin`
3. AppID 已配置：`wxa8d281cdb7130d59`（project.config.json 自动生成）
4. 详情 → 本地设置 → 勾选「不校验合法域名」用于本地联调

## 已实现功能

- 邮箱验证码注册 / 登录 / 找回密码
- 任务：三状态流转（计划中→执行中→已完成，自动记录开始/完成时间、支持回退/重开）、
  紧急程度（一般绿/紧急黄/重要红）、任务类型（个人/工作）、计划开始/截止时间、删除二次确认
- **子任务系统**（与桌面端一致）：任务标题多行输入，`1. xxx` 或 `- xxx` 自动转成勾选子任务，
  卡片上直接点击勾选切换完成状态，带进度条
- **长按拖拽排序**：长按任务卡片拖动调整顺序（浮起+让位动画），松手落位并同步 `sort_order`，
  与桌面端/其他端数据互通
- 列表触底反弹动画（滑到底内容区回弹）
- 备忘：列表 / 搜索 / 新建 / 编辑 / 删除（主页面「备忘」标签切换，与桌面端一致）
  **支持 Markdown 渲染**：标题、加粗、列表、代码、引用、链接等自动排版（markdown-it + mp-html）
- **实时同步**：WebSocket 长连接（wss://work.jspang.com/ws，30s 心跳、断线 5s 重连），
  桌面端等其他设备修改后小程序**自动刷新**（无需手动下拉）；60s 轮询兜底；
  切后台回前台自动重连 + 拉全量
- 云同步：登录后自动同步任务与备忘（与桌面版共用云端，数据互通）
- **功能菜单**（主页面左下角 ☰）：云端同步 / 我的数据 / 循环任务 / 个人中心
  （底部无 tabBar，个人中心从功能菜单进入）
- 个人中心：账号信息、退出登录

## 与桌面端 UI 对齐说明

- 主页面顶部 5 个筛选标签：计划中 / 执行中 / 已完成 / 全部 / 备忘（带计数）
- 内容区支持**左右滑动切换**标签（swiper，iOS 交互习惯），点击标签与滑动双向联动
- 每个滑页内独立滚动，支持下拉刷新（scroll-view refresher）
- 任务卡片：左侧紧急度色条 + 彩色边框（一般绿/紧急黄/重要红）、
  主标题、状态·时间副标题、子任务进度条、可勾选子任务列表、
  底部标签（紧急度/类型/计划开始/截止）+ 开始/完成/重开、修改、删除按钮

## 上线前必做清单

1. **配置 request 合法域名**：小程序后台 → 开发管理 → 开发设置 → 服务器域名 →
   添加 `https://work.jspang.com` 到 request 合法域名（当前 `urlCheck: false` 仅限开发）。
2. **配置 socket 合法域名**：同上页面 → socket 合法域名 →
   添加 `wss://work.jspang.com`（实时同步 WebSocket 需要）。
3. **填写用户隐私保护指引**：小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引
   （登录需收集邮箱、任务内容需存储；小程序端不调用 AI，勿声明向第三方 AI 共享数据）。
4. **备案**：确认该小程序已完成 ICP 备案（2023-09 起所有小程序上架前必须备案）。
5. **服务类目**：按功能选择「工具 > 效率」等类目。小程序端**不含任何 AI 生成功能**
   （个人主体不开放「深度合成-AI 创作」类目）：AI 日报/周报页、额度页、`/api/ai/*` 调用
   与协议里的 AI 条款均已移除；桌面端仍保留 AI 能力，后端接口不变。
6. **提审材料**：准备测试账号（邮箱+密码），填写提审备注说明功能用途。
7. **正式发布前**：把 `manifest.json` 中 `mp-weixin.setting.urlCheck` 改回 `true` 再重新构建。

## 与桌面版同步说明

- 小程序以本地缓存为数据源，任何操作先落本地，再全量上报 `/api/tasks/sync`、`/api/memos/sync`，
  服务端按 `updated_at` 较新者胜出（LWW）合并后返回云端全量覆盖本地。
- 与桌面版 / Android 版登录同一账号即可互通；删除走软删除并同步到其他端。
